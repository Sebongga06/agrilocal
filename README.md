# Installation

## Requirements
- XAMPP
- PHP
- MySQL
- Web Browser

## Steps to Run

1. Download or clone the repository.
2. Copy the project folder into the `htdocs` folder.
3. Start Apache and MySQL in XAMPP.
4. Open phpMyAdmin.
5. Create a database named:

```plaintext
db_agrilocal.sql
```

6. Import the provided `.sql` file.
7. Open your browser and type:

```plaintext
http://localhost/AgriLocal_1/public/index.php
```

# Usage

## Vendor Account


## How to Use

1. Login using the vendor account.
2. Navigate using the menu.
3. Add new products.
4. Edit or delete products.
5. Manage orders. 
7. Logout after using the system.
 


---
## Buyer Account


## How to Use

1. Login using the buyer account.
2. Navigate using the menu.
3. Browse the available products.
4. Add to favorites.
5. View favorites.
6. Add products to the cart.
7. Check out the products.
8. View vendor stores.
9. Logout after using the system.
